Module Big Data & Analyse de données

Travaux pratiques Hadoop, Hive et Spark

Huit TP progressifs : installer Hadoop sur un poste, monter un cluster, le transposer dans le cloud, interroger les données en SQL, calculer en mémoire avec Spark sur une machine puis sur le cluster, passer aux DataFrames, et finir sur une plateforme managée (Databricks). Fil rouge : les ventes d'une enseigne, analysées par ville, catégorie et moyen de paiement.

Avant de commencer

Ce qu'il faut prévoir, et le lien entre les TP et les chapitres du cours.

Matériel et comptes

  • TP1 : Ubuntu Server 26.04 LTS (machine ou VM), 8 Go de RAM recommandés.
  • TP2 : VirtualBox et un poste de 16 Go de RAM recommandés (4 VM de 2 Go).
  • TP3 : un compte AWS. Les instances sont facturées à l'heure : arrêtez-les après chaque séance.
  • TP4 : Docker Engine et Docker Compose V2, 8 Go de RAM disponibles pour Docker.
  • TP5 : la VM du TP1 (8 Go de RAM recommandés) et 5 Go d'espace disque libre.
  • TP6 : les 4 VM du TP2, passées à 3 Go chacune (poste de 16 Go de RAM).
  • TP7 : la VM du TP5 (Spark 4.2.0 sur YARN) et les données du TP5 dans HDFS.
  • TP8 : un navigateur web et un compte Databricks Free Edition (gratuit, sans carte bancaire).
